# 小动物养成乐园 - 独立桌面 App

## 下载

| 文件 | 大小 | 说明 |
|---|---|---|
| `小动物养成乐园.zip` | ~99 MB | **推荐** Windows 便携版，解压即用 |
| `小动物养成乐园.7z` | ~63 MB | 7z 高压缩版，需安装 7-Zip 解压 |
| `小动物养成乐园.exe` | 181 MB | 单独 exe（需配合同目录 dll 文件） |

## 安装步骤（Windows）

### 方式一：ZIP 便携版（推荐）

1. 下载 `小动物养成乐园.zip`
2. 右键 → **解压到当前文件夹**
3. 进入解压后的 `win-unpacked` 文件夹
4. 双击 **`小动物养成乐园.exe`** 即可运行

### 方式二：7z 高压缩版

1. 下载 `小动物养成乐园.7z`
2. 用 [7-Zip](https://www.7-zip.org/) 解压
3. 进入 `win-unpacked` 文件夹
4. 双击 **`小动物养成乐园.exe`**

## 使用说明

- 首次打开选择喜欢的小动物并命名
- 所有数据自动保存在电脑本地，关闭再打开不会丢失
- 适合 Windows 10/11 系统
- 无需联网，完全离线运行

## 功能

- 多角色选择（小兔子/小猫咪/小狗狗/小熊猫/小狐狸/小仓鼠）
- 加分任务 & 扣分项（全部可自定义编辑）
- 金币商店（食物/玩具/药品）
- 喂养/陪玩/治病交互 + 音效
- 日报周报 + 心愿兑换
